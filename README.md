# Hei, olen Tony 👋

Ohjelmistokehittäjäopiskelija Helsingistä (Taitotalo). Rakennan työkaluja tekoälyagenteille, ja toivottavasti niistä joskus voisi olla hyötyä jollekin muille. 

## Projektit

- **[mcp-server-git-history](https://github.com/tonyweckstrom1987/mcp-server-git-history)**: MCP-palvelin, joka antaa tekoälyagenteille työkalut Git-historian lukemiseen ja hakemiseen (julkaistu npm:ssä).
- **[gitstandup-ai](https://github.com/tonyweckstrom1987/gitstandup-ai)**: muuntaa Git-commit-historian AI:n avulla standup-, LinkedIn- tai oppimispäiväkirjayhteenvedoksi.
- **[github-linkedin-post](https://github.com/tonyweckstrom1987/github-linkedin-post)**: hakee GitHub-repot ja muotoilee niistä LinkedIn-postausluonnoksen.
- **[cli_project](https://github.com/tonyweckstrom1987/cli_project)**: CLI-chatbot, joka käyttää MCP:tä dokumenttien hallintaan Claude API:n kanssa.

## Teknologiat

JavaScript · Python · Node.js · MCP (Model Context Protocol) · Git · GitHub Actions
