Ohjelmistokehittäjäopiskelija Helsingistä (Taitotalo), aiemmin lähihoitaja. Rakennan avoimen lähdekoodin työkaluja tekoälyagenteille (MCP-palvelimet, LLM-infra) ja etsin työharjoittelupaikkaa vuodelle 2027 (AI-infra, backend tai terveysteknologia).

## Projektit

- **[mcp-server-git-history](https://github.com/tonyweckstrom1987/mcp-server-git-history)**: MCP-palvelin, joka antaa tekoälyagenteille työkalut Git-historian lukemiseen ja hakemiseen (julkaistu npm:ssä ja virallisessa MCP-rekisterissä).
- **[mcp-model-router](https://github.com/tonyweckstrom1987/mcp-model-router)**: MCP-palvelin, joka täydentää LiteLLM:ää — mallin valinta tehtävätyypin mukaan, kulutuksen seuranta ja eval-vertailu.
- **[cli_project](https://github.com/tonyweckstrom1987/cli_project)**: CLI-chatbot, joka käyttää MCP:tä dokumenttien hallintaan Claude API:n kanssa.
- **[gitstandup-ai](https://github.com/tonyweckstrom1987/gitstandup-ai)**: muuntaa Git-commit-historian AI:n avulla standup-, LinkedIn- tai oppimispäiväkirjayhteenvedoksi.
- **[github-linkedin-post](https://github.com/tonyweckstrom1987/github-linkedin-post)**: hakee GitHub-repot ja muotoilee niistä LinkedIn-postausluonnoksen.
- **[harjoittelutracker](https://github.com/tonyweckstrom1987/harjoittelutracker)**: Node.js/Express + SQLite -sovellus harjoittelupaikkahakemusten seurantaan.
